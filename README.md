# Giro d'Italia Rugnummerzoeker

Een mobiel-vriendelijke webapp om snel rugnummers van wielrenners in de Giro d'Italia op te zoeken.

## Features

- Snel rugnummers opzoeken
- Direct weergave van renner-informatie
- Mobiel-vriendelijke interface
- Numeriek toetsenbord voor snelle invoer

## Installatie

```bash
# Installeer dependencies
npm install

# Start development server
npm run dev

# Build voor productie
npm run build
```

## Technologieën

- React
- TypeScript
- Vite
- Material-UI

## Ontwikkeling

De app draait op `http://localhost:5173` in development mode.
